-----CARA COMMIT & PUSH-----
1. git config user.name "nama_kamu"
2. git config user.email "email_kamu"
3. git add .
4. git status
5. git commit -m "pesan commit"
6. git push origin main

(Jika No.6 ERROR/REJECTED karena ada kode baru di GitHub yang belum kamu ambil, lakukan langkah ini):
-> git pull origin main --rebase
-> (Jika ada bentrok/conflict, perbaiki kodenya di VS Code, lalu ketik 'git add .' kemudian 'git rebase --continue')
-> Jika rebase sudah selesai, lakukan kembali No. 6: git push origin main

-----CARA PULL (Biar Riwayat Git Rapi)-----
1. git pull origin main --rebase
